# Knobloch Syndrome and Amniotic Membrane Grafting — Literature Review

An interactive literature review supporting a case report on dual-site amniotic membrane grafting for bilateral macular hole–related retinal detachment in a child with Knobloch syndrome.

**[View the review →](https://yazeedalrayani.github.io/Knobloch-Literature-Review/)**
*(link works once GitHub Pages is enabled — see below)*

---

## Contents

A single self-contained HTML file, `index.html`, with ten sections:

| Section | Covers |
|---|---|
| Overview | Scope, method, and the four points the literature establishes |
| Key Numbers | Every statistic used, with its population and source |
| Case Register | All 13 published grafts in Knobloch syndrome, case by case, plus extramacular and paediatric applications |
| The Disorder | Phenotype, mechanism, associations beyond the eye |
| Detachment | The three cohorts and their outcomes |
| Refraction | Refraction and axial length across the literature |
| Amniotic Membrane | Mechanism, placement conventions, failure modes |
| Case Tables | Per-eye and per-patient data from primary sources |
| Positioning | What is and is not supported by the evidence |
| References | 44 references, numbered and cross-linked, 12 starred as key |

## Features

- **Cross-linked citations** — every `[n]` in the text jumps to the reference and highlights it
- **Starred key references** with expandable notes on relevance to the case
- **Copyable DOIs** and direct links to doi.org and PubMed
- **Searchable, filterable** reference list
- **Dark mode**, following system preference by default
- **Print-friendly** — all sections and expandable notes open automatically when printing

No build step, no dependencies, no external assets. Open `index.html` in any browser.

## Sources

Literature retrieved from PubMed and MEDLINE, supplemented by Consensus across Semantic Scholar, Scopus, PubMed and arXiv. Search strings are documented in the Overview section. Nine papers were read in full text; entries marked *abstract only* are cited from the abstract. Literature current to August 2026.

All 44 references were resolved against PubMed. Four citation errors carried in an earlier draft were corrected: Khan 2012 pagination, Alzaben 2024 issue number, Abdullah 2025 pages, and the Tartaro 2022 title.

## A note on the case data

This review includes a small amount of unpublished case data — ages in months, biometry, genotype and surgical configuration — shown alongside the published literature for comparison. It contains **no patient name, medical record number, calendar dates or institution identifying the patient**.

Two things worth deciding before making the repository public:

1. **Journal policy.** Most journals permit preprints and working documents, but a few treat public posting of case data as prior disclosure. Worth a glance at the target journal's policy if the repository will be public before submission.
2. **Institutional review.** The ethics approval covers journal publication. Public web posting is a separate act and may warrant a note to the IRB.

A **private repository with the supervisor added as a collaborator** avoids both questions entirely and works just as well for review.
